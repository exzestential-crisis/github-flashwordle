# GitHub Flash Wordle

Play Wordle directly in GitHub via issues!

![Wordle Board](./data/board.png)
[![Add Guess](https://img.shields.io/badge/Add%20Guess-Click-blue)](https://github.com/exzestential-crisis/github-flashwordle/actions/workflows/workflow_dispatch.yml)

### How to Play

1. Open a new issue and title it with your 5-letter guess.
2. Or comment on an existing issue with your guess.
3. The board image will update automatically after a few seconds.
